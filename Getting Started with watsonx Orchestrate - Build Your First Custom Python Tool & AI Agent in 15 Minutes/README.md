# 📝 WXO Labs Blog & Publishing Asset Package

This package contains all publishing assets, markdown drafts, visual branding, and the standalone HTML presentation for the **WXO Labs: From Zero to Hero** blog series.

---

## 📁 Package Contents

| File | Description | Target Use |
|---|---|---|
| **[`ibm_community_post.html`](./ibm_community_post.html)** | **Clean, simple semantic HTML (Sanjita Gupta style)** | Paste directly into IBM Community Source Code (`<>`) editor |
| **[`index.html`](./index.html)** | Standalone, rich dark-mode web presentation with copy buttons | Host on GitHub Pages or view in local browser |
| **[`wxo_labs_icon.jpg`](./wxo_labs_icon.jpg)** | 1:1 Square App Icon / Series Badge (3D glassmorphic flask with AI neural nodes) | Series avatar, square thumbnails, social badges |
| **[`wxo_blog_banner.jpg`](./wxo_blog_banner.jpg)** | 16:9 Wide Cybernetic Header Banner | IBM Community blog header image, LinkedIn cover |
| **[`IBM_COMMUNITY_BLOG_LAB1_BEGINNER.md`](./IBM_COMMUNITY_BLOG_LAB1_BEGINNER.md)** | Focused 15-minute hands-on tutorial for Lab 1 (First Python Tool & Agent) | Ready to copy & paste if using markdown |
| **[`IBM_COMMUNITY_BLOG_WXO_LABS.md`](./IBM_COMMUNITY_BLOG_WXO_LABS.md)** | Comprehensive 15-Lab overview announcement blog post | Alternative macro-overview announcement post |

---

## 🚀 Quick Actions

### 1. View the HTML Blog Page Locally
```bash
open index.html
```

### 2. Publish to IBM Community
1. Log in to the [watsonx Orchestrate - IBM Community](https://community.ibm.com/community/user/groups/community-home/recent-community-blogs?communitykey=3ad46381-9535-462e-85c9-568b21f4b067).
2. Click **Create Blog Post**.
3. Upload `wxo_blog_banner.jpg` as the featured cover image.
4. Click the **Source Code** (`<>`) button in the IBM Community editor and paste the contents of `ibm_community_post.html` (all images render automatically!). Alternatively, use `IBM_COMMUNITY_BLOG_LAB1_BEGINNER.md`.
5. Set tags: `watsonx Orchestrate`, `Python`, `AI Agents`, `Developer Tutorial`, `MCP`.
