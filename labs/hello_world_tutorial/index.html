Why Custom Tools Matter

Large Language Models (LLMs) are great at conversational synthesis, but without tools, they operate in isolation. They cannot query your corporate database, call an internal microservice, or run deterministic calculations.

In IBM watsonx Orchestrate (WXO), tools give your AI agents hands and feet. You can write custom logic in plain Python, decorate it with @tool, and publish it directly to your catalog. From there, the agent autonomously extracts parameters from conversational user requests and runs your code.

In this hands-on tutorial (adapted from Lab 1 of our WXO Labs & Tutorial Guide), we will write a custom Python greeting tool, import it into WXO, deploy a native AI agent, and interact with it in under 15 minutes.

📋 Prerequisites

Before starting, make sure you have Python 3.10+ and the official Orchestrate CLI installed:

Terminal 
# 1. Install the CLI
pip install ibm-watsonx-orchestrate

# 2. Verify active environment
orchestrate env list

🛠️ Step 1: Write Your Python Tool (greetings.py)

Create a dedicated workspace folder and create greetings.py:

greetings.py 
from ibm_watsonx_orchestrate import tool

@tool
def greet_user(name: str) -> str:
    """
    Generate a personalized greeting for a user.

    Args:
        name: The name of the person to greet.

    Returns:
        A friendly greeting message.
    """
    return f"Hello, {name}! Welcome to IBM watsonx Orchestrate."
💡 How Watsonx Orchestrate Reads Your Code

Notice how clean this is. The @tool decorator inspects your Python type hints (name: str) to dynamically generate the JSON Schema. Furthermore, the LLM reads the docstring to understand when to call the tool and which arguments to parse from the user prompt.

📦 Step 2: Create requirements.txt

Tell the Orchestrate runtime what dependencies your tool requires:

requirements.txt 
ibm-watsonx-orchestrate>=2.9.0

🚀 Step 3: Import the Tool into WXO Catalog

Use the CLI to bundle and upload your Python tool:

Terminal 
# Import your Python tool
orchestrate tools import -k python -f greetings.py -r requirements.txt

# Verify it appears in your catalog
orchestrate tools list | grep greet_user

🤖 Step 4: Define Your AI Agent (agent.yaml)

Create an agent manifest that binds to your newly imported tool:

agent.yaml 
spec_version: v1
kind: native
name: hello_world_greeter
title: "Hello World Greeter"
description: "A friendly onboarding agent that greets users using custom Python tools."
model: ibm/granite-3-8b-instruct
instructions: |
  You are a friendly and welcoming assistant.
  When a user introduces themselves or asks you to greet someone, extract their name
  and call the `greet_user` tool to deliver a personalized welcome.
tools:
  - greet_user

🚢 Step 5: Deploy & Test Your Agent

Import and deploy your agent with two simple commands:

Terminal 
# Import the agent
orchestrate agents import -f agent.yaml

# Deploy to draft environment
orchestrate agents deploy -n hello_world_greeter

Now, test your agent conversationally in your terminal:

Terminal 
orchestrate chat ask -n hello_world_greeter "Say hello to Markus"
[INFO] - Using agent: hello_world_greeter

🎯 Challenge Exercise: Add Multi-Language Greetings!

Try modifying greetings.py to support a language parameter:

@tool
def greet_user(name: str, language: str = "en") -> str:
    """Personalized greeting in English, Spanish, French, or German."""
    greetings = {
        "en": f"Hello, {name}! Welcome to IBM watsonx Orchestrate.",
        "es": f"¡Hola, {name}! Bienvenido a IBM watsonx Orchestrate.",
        "fr": f"Bonjour, {name}! Bienvenue dans IBM watsonx Orchestrate.",
        "de": f"Guten Tag, {name}! Willkommen bei IBM watsonx Orchestrate."
    }
    return greetings.get(language.lower(), greetings["en"])

Re-import with orchestrate tools import -k python -f greetings.py -r requirements.txt and ask: "Say hello to Carlos in Spanish"!
